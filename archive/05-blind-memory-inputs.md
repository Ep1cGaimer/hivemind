# Blind company-memory paper packets

All organizations, projects, outputs and sessions below are fictional. Tool logs are AUTHOR-SPECIFIED PAPER FIXTURES, not executed agent runs. Four packets are independent; their identifiers carry no category meaning. No compatibility, benchmark or production claim follows.

Each packet has two prior role sessions and one proposed genuinely cold next session, C. C has no chat history but receives the same authorized packet facts. All packet material is permitted within its fictional scope. READ records show only what was exposed to a session. Memory write records show only that text was stored. A citation is CLAIMED support, not automatically reviewed support. No other reviewed support exists unless stated.

Task for each packet: quote the passages supporting your proposed claim-to-source links; distinguish observations, interpretations and missing evidence. Propose one specific clarification if needed. State exactly what cold session C may say/use and what it must leave unresolved. Do not derive truth, statistical independence, confidence, permission or consensus from source counts. Do not invent a human approver requirement. This concerns company capability/context for internal planning, not launch authorization.

Controls receive every identical passage, memory, log, correction and scope fact. A primary-source-only same-LLM control can directly read all original sources and reviewed corrections. A complete SQL/provenance control can use all serialized relationships. Neither must fail, and neither is restricted to misleading summaries.
