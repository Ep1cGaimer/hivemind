#### H11 — Anti-Echo Institutional Decision Memory
1. **Weakness**: Memory `READ` receipts only record retrieval events, not semantic premise support. Counting shared roots does not prove false consensus or epistemic dependence.
2. **No-Graph Baseline**: A flat origin-ID set intersection script combined with a mandatory owner-authorization rule catches single-source citations without graph infrastructure.
3. **Mature Substitute**: V6 (*Beyond Memory Majority*) directly formalizes latent correlated source detection; Graphiti/Glean already handle enterprise provenance.
4. **Missing Data**: Semantic premise attribution distinguishing independent corroboration from circular echoing in unstructured text.
5. **Overclaim**: That traversing common ancestor nodes proves consensus is an artificial echo chamber rather than true independent agreement.
6. **Demo Break**: Legitimate shared background context (e.g., an authoritative company wiki) falsely collapses separate field observations into a single root.
7. **ONE Repair**: Disclaim automated consensus scoring; anchor the graph strictly to explicit *claim-derivation links* where an agent quotes an earlier agent's output as primary justification.
8. **Cheapest Kill Test**: Run 15 multi-agent decision summaries against an origin-ID set intersection; if flat ID matching detects identical echo roots without graph traversal, kill it.

#### H03 — Coverage-Driven Knowledge Handover
1. **Weakness**: Closed-world fallacy: absence of recorded attestation in the graph does not prove sole human knowledge; colleagues often possess unrecorded tribal context.
2. **No-Graph Baseline**: Standard bus-factor metrics (git/wiki commit counts) paired with a generic LLM exit-interview prompt capture similar handoff notes.
3. **Mature Substitute**: Jira/Confluence ownership tables, service catalogs, and engineering analytics tools.
4. **Missing Data**: Unrecorded informal context, Slack discussions, and verbal architectural rationale.
5. **Overclaim**: That the graph autonomously uncovers true single-knower risks without hand-authored `SHOULD_ASK` targets in the fixture.
6. **Demo Break**: Departing employee states "Alice already knows this," rendering the graph’s sole-attestor alert a false positive.
7. **ONE Repair**: Reframe strictly as *attestation coverage over active dependent systems*: prioritize interview questions only where an uncorroborated decision links directly to downstream production components (`Decision -> IMPLEMENTED_IN -> Service`).
8. **Cheapest Kill Test**: Run a generic exit interview with identical question budgets; if the successor cold-start agent answers operational questions with equal accuracy, kill it.

#### H06 — Two-Sided Acceptance Handoff Memory
1. **Weakness**: A missing `ACCEPTED` edge reflects unrecorded or delayed logging, not customer refusal. Curating explicit `Scope` vs. `Acceptance` edges does all the heavy analytical work.
2. **No-Graph Baseline**: A structured CRM onboarding checklist (e.g., Gainsight/Salesforce CPQ) with boolean milestone sign-offs detects unaccepted scope without an LLM.
3. **Mature Substitute**: Gong (V8) already tracks customer promises and follow-up action items; Gainsight/Planhat manage deliverable handoffs.
4. **Missing Data**: Granular customer acceptance emails, verbal SOW amendments, and post-sales change orders.
5. **Overclaim**: That extracting "migration included" vs. "one-time CSV accepted" is a graph-native problem rather than standard NLP entity extraction.
6. **Demo Break**: The customer verbally agreed to scope, but because no formal `Acceptance` node exists, the agent falsely flags a critical onboarding blocker.
7. **ONE Repair**: Require the agent to cross-check extracted SOW commitments against verified delivery receipts, marking unlinked deliverables as `UNKNOWN_ACCEPTANCE` rather than hard blockers.
8. **Cheapest Kill Test**: Ingest 10 messy handoff transcripts; if a standard Gainsight checklist or flat tabular LLM isolates identical scope gaps, kill it.
