# Author oracle — keep separate from blind responses

These are author-specified synthetic paper cases, not observed agent runs, model accuracy or tested capabilities. Admissible answers can differ in wording. An author's preferred answer cannot resolve a genuine ambiguity. Evaluate justified scope and evidence use, not agreement with a hidden verdict.

## Common interpretation rules

- Exposure, write provenance, claimed support and reviewed support are separate. READ is never a claim-support edge.
- Unreviewed citations can support a proposed interpretation when actual text warrants it; they are not automatically false or unusable. Reviewed scope must still be respected.
- Shared documents can contain unrelated background. Do not collapse observations merely because sessions read the same item. Separate run IDs identify separately recorded outputs, not statistical independence or truth.
- No numeric consensus, origin-derived permission, invented authority requirement, broad capability certification or automatic action follows.
- C is a cold third session. Credit only memory use actually traceable to the prior role output/review. Directly rereading the originals is an equally legitimate control and may be preferable.

## Fixture limitations and rejection interpretation

All four packets are tiny, entirely authored and linguistically explicit. Span citations make support tracing easier than uncontrolled company memory. Missing links may reflect incomplete logging. Reviewed correction R-6 is assumed authentic inside the fixture, not validated review infrastructure. No packet establishes demand, cost savings, permissions correctness, actual rollout behavior or performance.

The strongest fixed control must retain all qualifiers, distinguish source types, preserve unknowns, honor exact review scope and use current originals/corrections. Give a primary-source-only same-LLM control every identical fact; do not force it to rely on derivative summaries. Complete SQL/provenance with the same LLM is an allowed equivalent implementation. Neither parity itself nor finite-rule emulation disproves meaningful agents.

H11's differentiation is weakened or rejected if qualified primary-source retrieval or a configured source/review system supplies the same useful cold-session action with less setup, or if the memory layer adds only repetition/citation animation. H11's safety/semantic design is falsified by systematic READ-as-support, shared-background collapse, correction leakage across scope, or promotion of unknown support. Require a separate actual experiment before claiming runtime accuracy; these author expectations are not benchmark results. Do not grow infrastructure or hide source facts to manufacture a win.
